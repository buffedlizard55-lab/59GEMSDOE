Target-group background / mapping-effort status

The user-requested Phillips et al. (2009) target-group background is NOT IMPLEMENTED. The pinned package has the response fault traces, an external state-fault compilation, fault attributes and GeoDAWN geophysical rasters, but no independently verified, spatially matched same-effort inventory of non-target mapped structures. The response catalogue cannot be reused as its own target group. USGS reliability-of-location, road-access and official GeoDAWN acquisition-block layers are not pinned. The State Geologic Map Compilation is a fault map, not a defensible neutral mapping-effort sample.

Verification status: every hash above was recomputed from the bytes in this repository (scripts/prepare_data.py --fetch verifies on restore). This authenticates the bridge bytes, not organizer provenance. Sandbox egress is limited to GitHub, npm and PyPI hosts; ScienceBase / DrivenData were not accessed. Any future target-group source requires a separate provenance, license, coverage and coordinate audit before modeling.
