Exactly how to submit — four steps

  1. Download. Click the green button above and save gems59-h59a-intensity-zone-breakeven-8c0c6142-zeros.tif. A .zip containing exactly one GeoTIFF is offered as well; the portal accepts either.
  2. Open the submission page. drivendata.org/competitions/306/competition-doe-gems/submissions/ → New submission.
  3. Choose the file. File to submit → pick the .tif (or the .zip). Do not upload an HTML page, a JSON receipt, a PDF, or a zip of this repository — those are rejected.
  4. Paste the name and the note shown above, then submit.

The error we hit, and why this file cannot hit it

"Predicted values must be in range [0, 1]" is returned when the array contains a value outside [0, 1]. A raster that stores NaN outside the bounds satisfies the rules ("data outside the bounds is null or nan") but fails the portal, whose range check reads every cell. This release therefore writes 0.0 outside the footprint, so every cell is finite and inside the range; scripts/submission_writer.py re-reads and re-validates the file it wrote, and the result is printed on this page.
