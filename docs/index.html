What this file is

A binary dot field. Dots sit on a 3 px lattice in 1 km blocks the model ranks highest for unmapped fault density, with the mapped catalogue masked out. It is not a probability map and not a copy of any earlier raster.

What it is not

Not an organizer-confirmed score. Both holdout frames are proxies; the catalogue frame is structurally biased toward near-catalogue placement and the off-catalogue frame is a different public catalogue, not the organizer's hidden truth.

The one comparison that decided the release

At a matched budget (44,000 dots each), the two frames rank the fields in opposite order: the catalogue frame prefers pure proximity to the mapped traces, the off-catalogue frame prefers the ground-only field by 61 %. Because the scored target is faults absent from the catalogue — and the owner-reported live evidence penalises catalogue-adjacent dots — the release follows the off-catalogue frame and reports the catalogue-frame cost explicitly.
