2. How to submit (executive summary)

  1. Download the .tif from section 1 (or the .zip containing a single GeoTIFF).
  2. Log in to the competition at drivendata.org/competitions/306/competition-doe-gems. Open the submission page and choose New submission.
  3. Under File to submit, choose the downloaded file. The portal accepts a single-band GeoTIFF or a zip with one GeoTIFF, and it must match the submission format's CRS, shape and geotransform.
  4. Under Note, paste the note from the receipt (at most 140 characters). Use the unique name in the note so runs can be told apart later.
  5. Submit. The portal reports the result on the leaderboard once scoring finishes. Copy that number into the receipt as an ORGANIZER-CONFIRMED score.

Upload is a manual step by design: the portal needs your own DrivenData login. The build sandbox has no DrivenData login, so it cannot upload.

5. Why a sparse binary file can score well (judgement, with evidence level)

DERIVED

The official score is DTI = TP / (0.2·(TP+FP) + 0.8·G). A dot pays only if its kernel credit exceeds 0.2·DTI, about 0.056 at score 0.28. That is about 283 m from a true fault, not a density of 1–2 %. derivation

VERIFIED-FILE

The 0.2778 candidate file in GEMSDOE32 is binary (0 and 1), uses 37,654 dots (0.73 % of the 5.17 M-cell footprint), and passes our independent format check. The file-to-participant link is still unconfirmed.

IRREGULARITY

GEMSDOE32 charges dots on known faults as penalties. Staff say those pixels are masked and do not count toward the penalty terms. That proxy is therefore miscalibrated against the official rule. staff answer

SYNTHETIC

The exact emission rule holds in 500 of 500 random trials. The "about 3 px spacing" claim is not reproduced on a synthetic line, so it stays unconfirmed. evidence

Honest answer to "can we beat 0.2778?" Not demonstrated. It needs the organizer data and a holdout built with the official mask. Any claim of a higher score before that would be a projection, and none has been made.

6. Candidate hypotheses (none validated)

  1. H-1, thermal-spring alignment prior (rank 1). Independent spring locations mark conduits, which can reveal faults the catalogue lacks. Mimic: valley groundwater discharge. Download still to be verified.
  2. H-2, gravity horizontal-gradient maxima (rank 2, demoted). Blakely & Simpson (1986). It overlaps the registry's multi-physics lane (H33-A), so it is treated as a component, not a separate lane.
  3. H-3, regional gravity compilation (rank 3). An upgrade to the supplied gravity layers. Listing verified, download not.
