What this repository does

It fits a presence-only Poisson point-process intensity for faults from the published catalogue, corrects it for mapping effort, aggregates it to 1 km blocks, and then tiles only the blocks whose predicted fault density clears the break-even bar implied by the organizer's own scoring equation. Nothing else.

The one equation

DTI = TP_w / (TP_w + 0.2·FP_w + 0.8·FN_w), FN_w = |G| − TP_w  ⟹  DTI = TP_w / (0.2·TP_w + 0.2·FP_w + 0.8·|G|)

Differentiating with respect to the mass emitted at one pixel: emit a pixel iff its expected kernel weight Δ(x) ≥ 0.2 × DTI. At the group's incumbent 0.2778 that bar is 0.0556; for a 1 km block it means 1.85 px of fault trace per 100 px block — the "a lattice only pays above ~1–2 % density" rule, derived rather than assumed. See Research & method.
